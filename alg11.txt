dp(동적 계획) 알고리즘
부분 문제외의 의존 관계

분할 정복과의 차이: 작은 크기의 문제가 어디에 사용되는지
분할 정복은 부분 문제의 해를 중복 사용하지 않음


모든 쌍 최단 경로
-플로이드 워셜 알고리즘
시간복잡도 O(n^3) -> 다익스트라 알고리즘 n번과 동일
다익스트라보다 효과적,간단하다(이해가 쉽다고는 하지 않음)

s -> m -> e
void Floyd_Warshall() {
    for(m=1; m<=N; m++)
        for(s=1; s<=N; s++)
            for(e=1; e<=N; e++)
                if (d[s][e] > d[s][m] + d[m][e])
			    d[s][e] = d[s][m] + d[m][e];
}

연속 행렬 곱셈
연속된 행렬들의 곱셈에 필요한 원소 간의 최소 곱셈 횟수를 찾는 문제
행렬곱은 결합법칙이 성립하므로, 곱셈 순서를 바꾸어도 결과는 같음
